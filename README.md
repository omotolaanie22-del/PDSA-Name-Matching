**Name Matching and Data Quality Improvement Using Python and SQL**

**MSc Data Science Dissertation Project**

This repository contains my MSc Data Science dissertation project, which explored name matching and standardisation to support data quality improvement in an organisational context.

The project focused on developing a Python-based workflow for processing name data, identifying variations, and exploring matching approaches that could support future SQL-based implementation.

**Project Overview**

Inconsistent name data can create challenges for data management, reporting and the identification of matching records.

This project explored how data science techniques can be used to improve the consistency of name data through:

* Data profiling and exploration
* Name normalisation
* Language and origin detection
* Transliteration and standardisation
* AI-assisted name variant generation
* Rule-based matching
* Fuzzy matching
* Matching validation and reporting
* SQL-ready data structures and demonstration scripts

**Objectives**

The main objectives of this project were to:

1. Explore the quality and structure of name data.
2. Develop a workflow for name normalisation and standardisation.
3. Investigate methods for identifying variations in names.
4. Explore matching approaches for improving name consistency.
5. Develop SQL demonstration structures to support future deployment.
6. Evaluate the outputs of the developed workflow.
